สรุป Go เฉพาะส่วนที่ใช้จริงในงาน backend อ่านตามลำดับ sidebar ได้เลย

| ส่วน | หมวด | เนื้อหา |
| --- | --- | --- |
| ภาษา | เริ่มต้น → Packages และ Modules | syntax, type, error, module |
| Concurrency | Concurrency, Generics | goroutine, channel, sync, context |
| Backend | HTTP และ API → Deploy | net/http, Fiber, PostgreSQL, GORM, testing, Docker |

ทุก snippet เป็นโปรแกรมจริงที่ผ่าน test อยู่ใน `examples/go/<หมวด>/<หน้า>/` ศัพท์เทคนิคคงเป็นอังกฤษ ดู [Glossary](/dim-kb/th/go/reference/glossary/)
